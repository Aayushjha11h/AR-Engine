# AR-Engine

A game engine project built with C++.

## Project Structure

- `engine/` - Core engine components
- `Language/` - Language-related files
- `ThirdParty/` - Third-party dependencies
- `assets/` - Game assets
- `main.cpp` - Entry point

## Building

This project uses Visual Studio and can be built using the provided `.vcxproj` files.
